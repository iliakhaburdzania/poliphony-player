      Drag a note to move it in time and pitch; drag its right end to change its length. Drag on empty space to select several notes, Shift-click to add one.       Each bar is a line of NOTE:BEATS tokens. Pitches are written as on the staff (F#4, Bb3, E5), r is a rest, beats count quarter notes (0.5 is an eighth). A ~ after the length ties the note into the next bar. Change a note, press Apply, and play again, or use Editing mode above the score.

      Singing mode needs your microphone. If the browser doesn't ask for it when you open this file directly, open a terminal in the file's folder, run python3 -m http.server, and open http://localhost:8000/.
